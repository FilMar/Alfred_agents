## Decision

A decision page is written after the design session ends, not while it runs. During the session the notes live anywhere else: the roadmap, the chat, a scratch file. When the shape stops moving, the page gets written once.

## Why

A name written too early keeps pulling the design back toward the old idea.

It happened on 2026-09-28. The `tl` schema was written to the wiki while its shape was still being argued. A second page replaced it the same day. The first page carried the old name of the thing: "event log" instead of "work archive". The schema grew to nineteen columns because every new column looked reasonable for an event log. The final shape has three tables and thirteen columns in the queryable one.

So the cost of writing early is not a wasted file. It is a design that drifts toward whatever the premature page called it.
