## Decision

Name a skill after the most famous figure whose iconic trait coincides with the skill's function — any pantheon (myth, history, science, pop), single word, and it must pass the bar test: hearing the name, you guess the function without footnotes. Current names follow this rule (platone, annibale, omero, ermes, mose, ulisse, ...).

## Why

Three eras, tested against each other:

1. **Figures (original)** — flavourful, but the name→function link was folklore.
2. **Professions (2026-07-22)** — functional but flavourless (gardener, quartermaster, oracle). Two rejected detours: plain functional names (`consolidate-memory` — dispatch matches on description, so technically sufficient, but it flattens per-role personality) and D&D classes (unconvincing after a full mapping).
3. **Figures, second era (2026-07-27, current)** — keeps the function link of the profession era and the personality of the first. Executed on branch `refactoring/skill-rename`: directories, frontmatter, `alfred.md`, `CLAUDE.md`, README and wiki references.
