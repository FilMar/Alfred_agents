## Decision

A note with `trust` under 0.2 is archived. The refiner writes `archived_at` with the day of the first archive.

An archived note:

- is hidden from the default `tb search`, so it adds no noise;
- keeps all its content, its refs and its backrefs;
- needs no care from the user, because the refiner handles it alone.

The archive is reversible. An explicit search that includes archived notes can still find one. That hit counts as a signal. On the next run `trust` is computed again. If it is 0.2 or more, the note is back in the default search and `archived_at` is cleared.

The threshold 0.2 is by eye. It is fixed after the first dry run, on the spread of `trust` over the real notes.

## Why

Keeping a note costs almost nothing. There are 793 notes, a few hundred KB. The cost is not storage. It is noise in search and notes to decide by hand. A hidden note has no noise, and a refiner that runs alone has no queue for the user.

Hiding comes before deleting for one reason: a hit measures retrieval, not value. A good note on a rare topic can sit at zero hits. Hiding it loses nothing.
