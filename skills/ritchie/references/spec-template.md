# Spec template

`SPEC.md` is written in step 1, next to the work, in Italian. The
Italian is deliberate: the spec is the domain in the user's words, and
the user is Italian.

One line per field. Drop the fields this domain does not need. No prose
between the bullets: the user reads it once and says "ok", or amends it.

---
